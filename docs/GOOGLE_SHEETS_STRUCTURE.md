# Структура Google-таблицы для интеграции

## Обзор

Приложение использует Google-таблицу для дополнительного логирования и зеркалирования данных.
**Supabase является источником истины.** Google Sheets — только зеркало для просмотра.

URL таблицы задаётся через переменную окружения `VITE_GOOGLE_SHEET_URL`.

## Требуемая структура листов

### Обязательные листы (создать вручную перед запуском):

| Лист | Назначение |
|------|------------|
| COMMON | Общие задачи (scope = 'common') |
| USERS | Список пользователей |

### Динамические листы (создаются автоматически):

| Лист | Назначение |
|------|------------|
| U_<telegram_id> | Личные задачи пользователя (создаётся при первом входе) |

## Заголовки столбцов (COMMON и U_*)

Все листы задач имеют единую структуру:

| Столбец | Описание |
|---------|----------|
| id | UUID задачи |
| title | Название задачи (неизменяемое) |
| description | Описание задачи |
| status | ideas / planned / in_progress / review / done |
| priority | 1 (Высокий) / 2 (Средний) / 3 (Низкий) |
| scope | common / personal |
| author | Имя автора |
| owner | Имя исполнителя |
| created_at | Дата создания |
| updated_at | Дата обновления |

## Лист USERS

| Столбец | Описание |
|---------|----------|
| telegram_id | ID пользователя в Telegram |
| name | Отображаемое имя |
| role | admin / user |
| active | true / false |

## Удалить следующие листы (если существуют):

- Tasks
- Announcements
- Comments
- ReadStatus
- UserRoles
- Sheet1
- AccessCodes
- LoginLogs
- Tasks_*

## Важные правила

1. **Title неизменяем** — после создания задачи название не обновляется в Google Sheets
2. **Прогресс через комментарии** — шаги записываются в комментарии, не в description
3. **Листы U_* создаются автоматически** — при первом входе пользователя

## Права доступа

- Сервисный аккаунт `aktrans-bot@aktrans-task-system.iam.gserviceaccount.com` должен иметь права **Editor** на таблицу
- Для кнопки "Google-таблица" достаточно прав на чтение для пользователей

## Секреты

| Секрет | Описание |
|--------|----------|
| GOOGLE_SERVICE_ACCOUNT_KEY | JSON-ключ сервисного аккаунта |
| GOOGLE_SHEET_ID | ID таблицы (из URL) |
