# Структура Google-таблицы для интеграции

## Обзор

Приложение использует Google-таблицу для дополнительного логирования и синхронизации данных.
URL таблицы задаётся через переменную окружения `VITE_GOOGLE_SHEET_URL`.

## Структура листов

### 1. COMMON (Общие задачи)

Лист для задач со `scope = 'common'`. Структура столбцов:

| Столбец | Описание |
|---------|----------|
| ID | UUID задачи |
| Название | Заголовок задачи |
| Описание | Описание задачи |
| Статус | ideas / planned / in_progress / review / done |
| Приоритет | 1 (Высокий) / 2 (Средний) / 3 (Низкий) |
| Автор | Имя автора |
| Исполнитель | Имя исполнителя |
| Создано | Дата создания |
| Обновлено | Дата обновления |

### 2. USERS (Список пользователей)

Лист со списком всех активных пользователей:

| Столбец | Описание |
|---------|----------|
| ID | UUID профиля |
| Telegram ID | ID пользователя в Telegram |
| Имя | Отображаемое имя |
| Роль | admin / user |
| Активен | true / false |

### 3. U_<telegram_id> (Личные задачи пользователя)

Индивидуальные листы для личных задач (`scope = 'personal'`).

**Важно**: Листы `U_<telegram_id>` создаются только после первого входа пользователя в систему.

Пример названия листа: `U_123456789`

Структура аналогична листу COMMON.

## Примечания

- Листы создаются вручную или через Google Apps Script (отдельная интеграция).
- Данные синхронизируются через edge function при наличии настроенного Google Service Account.
- Секреты `GOOGLE_SERVICE_ACCOUNT_KEY` и `GOOGLE_SHEET_ID` должны быть настроены в Lovable Cloud.

## Права доступа

- Таблица должна быть доступна для записи сервисному аккаунту.
- Для просмотра кнопкой "Google-таблица" достаточно прав на чтение.
