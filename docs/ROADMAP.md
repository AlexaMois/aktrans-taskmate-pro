## 🚀 АПРЕЛЬ 2026 (Спринт 3-4) - Функциональность

### Неделя 1-2: AI и автоматизация
**Цель**: Умный бот, меньше ручной работы

#### AI Enhancement
- [ ] Улучшить промпты Perplexity для структурированных сводок
- [ ] Автоэкстракция задач из стенограмм (action items)
- [ ] Автоматическое определение исполнителей по именам
- [ ] Распознавание дедлайнов ("до пятницы", "на следующей неделе")
- [ ] Priority detection (срочно/важно)

#### Telegram Bot
- [ ] Команды управления задачами:
  - `/mytasks` - Мои задачи
  - `/create` - Создать задачу
  - `/complete [id]` - Завершить
  - `/assign [id] [@user]` - Назначить
- [ ] Inline keyboard для быстрых действий
- [ ] Кнопки "Выполнено"/"В работу"/"Отложить"
- [ ] Изменение приоритета через кнопки

**Результат**: Бот сам извлекает задачи, пользователи управляют ими из Telegram

### Неделя 3-4: Web Dashboard
**Цель**: Полноценный веб-интерфейс

#### Frontend
- [ ] Аутентификация через Supabase Auth
- [ ] Список задач с фильтрами (статус, приоритет, исполнитель, дата)
- [ ] Drag & Drop для изменения статусов (Kanban board)
- [ ] Создание/редактирование задач
- [ ] Страница статистики:
  - Графики выполнения по дням
  - Top исполнители
  - Просроченные задачи
  - Среднее время выполнения
- [ ] Адаптивная верстка (мобильные устройства)

**Результат**: Полноценная альтернатива Telegram для работы с компьютера

## 🛠️ Tech Stack (текущий)

### Backend
- Supabase (PostgreSQL + Edge Functions)
- Deno/TypeScript для Edge Functions
- Row Level Security (RLS)

### Frontend
- React + TypeScript
- Tailwind CSS
- shadcn/ui компоненты
- Lovable.dev для быстрого прототипирования

### AI & Integrations
- Perplexity API
- Telegram Bot API
- Google Sheets API

### DevOps
- GitHub Actions (CI/CD)
- Supabase CLI для миграций
- Vercel/Netlify для фронтенда
